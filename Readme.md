# 🏥 e-Likita – Health Consultation Platform

A full-stack web application for online health consultations.  
Patients can report symptoms, view consultation reports, and track health data securely.  

## 🚀 Tech Stack

### Frontend
- ⚛️ [React](https://react.dev/) (with [TypeScript](https://www.typescriptlang.org/))
- 🎨 [Tailwind CSS](https://tailwindcss.com/) for styling
- 🛣️ [React Router](https://reactrouter.com/) for client-side routing
- 🔐 JWT Authentication (HttpOnly cookies + CSRF protection)

### Backend
- 🟢 [Node.js](https://nodejs.org/) + [Express](https://expressjs.com/)
- 🍃 [MongoDB](https://www.mongodb.com/) with [Mongoose](https://mongoosejs.com/)
- 🛡️ Secure authentication & role-based access
- 📅 Automatic timestamps for consultations

### Deployment
- 🌐 Frontend: [Netlify](https://www.netlify.com/)
- ☁️ Backend: [Vercel](https://vercel.com/) / [Render](https://render.com/) / [Railway](https://railway.app/)
- 📦 CI/CD from GitHub
